# Calculadora de Desconto

## Sobre o projeto:

Este projeto é uma **Calculadora de Desconto**, desenvolvida em **Python**.
O programa solicita o **valor da compra** e, de acordo com o valor informado, aplica uma porcentagem de desconto:

## Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até R$ 299,99: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.

## Como executar

1. Tenha o Python 3 instalado.
2. Clone ou baixe este repositório.
3. Execute o arquivo `app.py`.
4. Informe o valor da compra quando solicitado.
